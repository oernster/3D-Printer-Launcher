Getting started

Download once, set up a shared environment once, then it is all buttons.

  1. Download the latest Windows .exe from the GitHub Releases page and keep it next to the qidi-temps, VoronTemps and qidiwebcamdrestart folders.
  2. Install Python 3.11+, then create the shared venv once and pip install -r requirements.txt. The launcher uses that environment automatically.
  3. Open Manage printers to point each card at your printer's Moonraker host, API port and dashboard port.
  4. Press Start on a card, open the dashboard URL in a browser to check it, then add it to OBS as a Browser Source.
